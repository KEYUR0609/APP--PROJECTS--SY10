# Project: 01 
-> This project is a simple Library Management System developed in Python using Object-Oriented Programming (OOP) principles. It is designed to manage books and library patrons efficiently. The system allows users to add new books, register patrons, borrow and return books, display available books and registered patrons, search for books by title or author, and remove books from the library. The project demonstrates important OOP concepts such as classes, objects, methods, encapsulation, and object interaction. It also provides a simple menu-driven interface that makes the system easy to use.


# Project: 02
-> This project is a Dynamic Report Generator developed in Python. It allows users to create customizable reports using different templates and formatting options. The project demonstrates important Python concepts such as decorators, class methods, and magic methods. Users can create templates, generate reports dynamically, and format the output according to their requirements.


# PROJECT: 03 
-> This project is a Configurable Payment Processing System developed in Python using the Strategy Design Pattern. It allows users to select and process payments through different methods, including Credit Card, PayPal, and UPI. The Strategy Pattern makes the system flexible, maintainable, and easy to extend by allowing new payment methods to be added without modifying the main payment processing logic.
